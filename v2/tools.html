    How to use these tools

    Adapt first, adopt later.

    Every template here is field-tested but locally adapted before it works for you. We recommend three steps: read the design notes, run a one-week pilot with a single team, and only then institutionalise.

    If you can't find the toolkit you need — write to us. Where we have it, we'll share. Where we don't, we'll help you draft one.
